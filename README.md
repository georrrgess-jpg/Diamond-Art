# Lustra — Gem Mosaics

A calm gem-by-number game for the browser. Choose a geometric mandala, pick a numbered gemstone, and place faceted gems into matching sockets until the pale pattern turns into a finished mosaic.

## Run

There are no dependencies. For development, serve the folder over HTTP (ES modules don't load from `file://`):

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

To build the single-file version (used for the published artifact), run `python3 build.py`. It writes `dist/lustra.html` with all CSS and JS inlined.

## Controls

| | Desktop | Touch |
|---|---|---|
| Place a gem | Click | Tap |
| Place several | Click and drag | Drag with one finger |
| Pick a spot's gem number | | Press and hold the spot |
| Undo last stroke | `Ctrl`/`Cmd` + `Z`, toolbar | Toolbar |
| Zoom | Mouse wheel / trackpad pinch, `+` `-`, double-click empty space, toolbar | Pinch, double-tap, toolbar |
| Pan | Space + drag, middle or right drag, Move tool (pans keep gliding after a flick) | Two fingers, Move tool |
| Fit | `0`, toolbar | Toolbar |
| Find a spot | `F` / `H`, toolbar, or tap the edge arrow when no matching spots are on screen | Toolbar, edge arrow |
| Change gem | `1`–`9`, `[` `]`, arrow keys in the palette | Tap the palette |

## Features

- 150 geometric artworks in five levels (Beginner to Master, about 100 to 3,750 gems each), with a daily featured pick, search, level sections, favorites and a continue rail.
- 8 themes (menus plus the board's backdrop, plate and sockets).
- Autosave, undo, guide arrows, a minimap when zoomed in, a first-run guide, play-time tracking, a daily play streak and image export.

## Adding artworks

Read `tools/ARTWORK_GUIDE.md`. Validate with `node tools/check.mjs all` and preview with `tools/sheet.html?c=collection3` (served over HTTP) or `node tools/sheet-shot.cjs <port> <collection> <out.png>`.

## Architecture (`js/`)

- `gems.js`: gem and socket rendering. There are 7 shapes (round, oval, teardrop, marquise, square, rhombus, hexagon). Round, oval, teardrop, marquise and rhombus use a brilliant-cut facet layout; square and hexagon use a step cut. Lighting is computed in world space, so every gem shares one light direction. An LRU sprite cache keys each sprite by shape, aspect, size bucket, rotation bucket, colour and variant, and is capped by total pixel count.
- `artworks.js`: deterministic generators (`ring`, `fillRings` with symmetric row counts, hex lattice, a collision grid built from circle approximations) and the first 17 artworks. `collection2.js` adds 18 more . It also adds generators for curves (spirographs, rose curves), mirror-symmetric greedy packing, Pascal-triangle fractals, Truchet tiles and woven carpets. `collection3.js` (radial mandalas), `collection4.js` (lattices, tilings, polygons) and `collection5.js` (curves, spirals, packings, fractals) add 65 more, and `collection6.js`–`collection8.js` add 25 Expert and 25 Master pieces (mandalas; tilings; curves, packings and fractals). `themes.js` defines the 8 themes. `meta.js` is generated by `node tools/gen-meta.mjs` (run automatically by `build.py`) so the gallery shows gem counts without building every artwork. Socket id = generation index; each artwork has a `version`.
- `board.js`: camera, culling, rendering. The board is drawn once into an offscreen layer (viewport plus a 25% margin); panning, pinching and zooming only redraw that layer as a single image, and it is rebuilt sharp once the camera settles. Placed gems animate on top of the layer and are then drawn into it. When the zoom level changes, the nearest cached gem size is reused immediately and sharp sprites are generated in small batches during idle frames. The board also handles hit testing (spatial grid plus a point-in-polygon test on the shape outline), pointer and gesture state machine, placement animations, sparkles, hint, completion shimmer, thumbnail and PNG export.
- `app.js`: gallery (filters, favorites, continue card), palette, progress, settings, completion panel, autosave.
- `store.js`: IndexedDB key-value store (falls back to localStorage). Progress records are versioned and validated on load.
- `audio.js`: quiet synthesized WebAudio sounds, started on the first user gesture.

## Deferred / not yet built

- Free Color mode (recolouring, undo, separate progress). `store.progressKey(id, mode)` already supports a separate mode key.
- No nonvisual (screen reader) way to play on the canvas. Menus and controls are keyboard and screen-reader labelled.
